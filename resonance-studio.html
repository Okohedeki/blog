Resonance Studio

Work with one person’s voice inside a recording.

Listen to the supplied-track example ↗

One voice, one moment

Select a voice layer and a time window, adjust its emphasis, and compare the edited mix with the original. Solo lets you follow a voice on its own. Undo restores the previous edit; export saves the mix as a WAV file.

What the edit preserves

The editor adds only the selected contribution’s level change to the original mix. With supplied tracks, other voice tracks and samples outside the selection stay unchanged. Edits that would clip are rejected.

That distinction matters for imported recordings: separated tracks are estimates. Leakage can affect another person’s voice inside overlapping speech, even when the selected layer is the only one being edited.

How it is built

React inside a Tauri desktop application, with a separate local Python worker for speaker analysis and separation. The supplied-track example exercises the editor without running a separation model. Audio and video imports share the same editing canvas.

Current limits

The working edit changes level, not words, voice identity, or room acoustics. Imports are limited to five minutes and 250 MB. Processing and WAV export use mono 16 kHz audio; video is a synchronized preview, not an exported movie.

Edits last for the current session. Export before closing. Models and the worker are separate from the unsigned Windows build. This is a project preview; there is no public download yet.
