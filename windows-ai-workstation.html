03 / Desktop agents · Developer preview

Windows AI Workstation

A native Windows workspace for giving AI a task, reviewing its actions, and keeping the result.

The idea

Make document-oriented agent work available through a native desktop application: choose a folder, describe the task, approve specific actions, and inspect the output.

The first implementation

The WinUI 3 application connects to DeepSeek Harness. Each task owns a separate worker, with streaming responses, cancellation, structured approvals, output documents, and local SQLite history.

The default task profile requests approval for project reads and document writes. It has no shell and cannot edit original project files. Windows credential protection stores the configured connection.

The engineering focus

Native C# controls, a TypeScript bridge, explicit task lifecycles, and durable local records. The interface is local; the current model connection uses the DeepSeek cloud API. This is not a local-inference application.

Where it stands

This is the first developer-preview slice. Build and integration checks have been recorded using deterministic provider fixtures. A successful live-provider task, native accessibility review, and Windows 11 acceptance remain unverified.

MCP, additional agent adapters, local inference, coding diffs, and signed installation are not yet implemented. This page describes work in progress and does not offer a public download.
